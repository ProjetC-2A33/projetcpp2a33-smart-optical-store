# Projet C++ 2A33 - Smart Optical Store

## Branche: integration-METIERS-stock-employe

Cette branche contient l'intégration des fonctionnalités de gestion des stocks et des employés pour le projet Smart Optical Store.

### Fonctionnalités implémentées

- Gestion des stocks d'articles optiques
- Gestion des employés
- Interface utilisateur pour la gestion des opérations

### Prérequis

- Qt 5.15 ou supérieur
- Compilateur C++ compatible C++17
- CMake 3.10 ou supérieur

### Installation

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/ProjetC-2A33/projetcpp2a33-smart-optical-store.git
   cd projetcpp2a33-smart-optical-store
   git checkout integration-METIERS-stock-employe
   ```

2. Compiler le projet avec CMake et votre compilateur préféré.
